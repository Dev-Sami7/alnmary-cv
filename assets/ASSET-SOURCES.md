# Asset sources

- `images/abdullah.jpg`: original portrait supplied by the user. No visual retouching; CSS applies restrained presentation effects.
- `images/original-cv.jpg`: original CV supplied by the user.
- `documents/Abdullah-Alnumary-CV.pdf`: A4 PDF embedding the supplied original CV, preserving its content.
- `images/showroom-concept.jpg`: original AI-generated luxury car-showroom interface concept, created with the built-in Imagegen tool for this presentation. Not a screenshot of the original academic website.
- `images/restaurant-concept.jpg`: original AI-generated restaurant desktop interface concept, created with the built-in Imagegen tool. Not a screenshot of the original application.
- `images/cpp-concept.jpg`: original AI-generated C++ workspace concept representing the assignment's subject. Not an actual application screenshot.
- Exact generation prompts are embedded in the JPEG comment metadata. PNG originals are retained in the generation workspace. JPEG delivery copies preserve the generated composition.
- `fonts/alexandria.ttf`: Google Fonts, SIL Open Font License; see `Alexandria-LICENSE.txt`. Source: https://github.com/google/fonts/tree/main/ofl/alexandria
- `fonts/geist.ttf`: Google Fonts, SIL Open Font License; see `Geist-LICENSE.txt`. Source: https://github.com/google/fonts/tree/main/ofl/geist
- The earlier Manrope font and its license are retained for optional customization.
- `vendor/gsap.min.js`, `ScrollTrigger.min.js`, `ScrollToPlugin.min.js`: GSAP 3.13.0, obtained from the official GSAP npm distribution through jsDelivr. Original distribution comments are preserved. License: https://gsap.com/standard-license/
- Favicon, line icons, ambient geometry and all application code were authored for this website.

All runtime fonts, scripts and images are local. The generated images are explicitly labelled as interface concepts in the website.

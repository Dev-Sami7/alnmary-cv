# موقع عبدالله النماري الشخصي

مشروع كامل بـ HTML وCSS وJavaScript، بالعربية والإنجليزية، جاهز للفتح مباشرة أو للرفع إلى Netlify. جميع الخطوط والصور محلية، ولا يحتاج المشروع إلى npm أو خطوة بناء.

## تجربة الموقع على جهازك

1. فك ضغط الملف بالكامل.
2. افتح مجلد `abdullah-cv`.
3. افتح `index.html` في متصفح حديث مثل Chrome أو Edge أو Firefox أو Safari.

تأكد من فتح الملفات بعد فك الضغط، وليس من داخل برنامج الضغط. يجب بقاء مجلد `assets` وملفي `profile.js` و`script.js` وملف `styles.css` بجانب `index.html`.

## رفع الموقع إلى Netlify

1. سجّل الدخول إلى حسابك في Netlify.
2. افتح https://app.netlify.com/drop أو اختر من لوحة Netlify إنشاء مشروع عبر الرفع اليدوي (قد يظهر باسم Add new project ثم Deploy manually).
3. اسحب مجلد `abdullah-cv` الذي يحتوي `index.html` مباشرة إلى منطقة الرفع.
4. انتظر اكتمال النشر، ثم افتح رابط الموقع الذي تمنحه لك Netlify.
5. تأكد من أن الموقع متاح للعامة، وافتح الرابط من نافذة خاصة دون تسجيل دخول قبل تسليمه للدكتورة.
6. يمكنك تخصيص اسم الموقع من إعدادات المشروع، حسب الأسماء المتاحة في حسابك.

لا يحتاج هذا المشروع إلى Build command. ملف `netlify.toml` مرفق للإعدادات الأساسية. لا ترفع المجلد الأب إذا كان يحتوي مجلد المشروع فقط؛ المجلد الصحيح هو الذي تجد بداخله `index.html` مباشرة.

لتحديث نفس الموقع لاحقًا، افتح مشروعك الحالي في Netlify وارفع مجلد المشروع المحدّث في قسم Deploys، للحفاظ على رابط الموقع نفسه.

مرجع Netlify الرسمي: https://docs.netlify.com/deploy/create-deploys/#drag-and-drop

## تعديل المعلومات

افتح `profile.js` باستخدام VS Code أو محرر نصوص. معظم المعلومات والنصوص موجودة فيه، موزعة إلى:

- `person`: الاسم، البريد، واتساب، تيليجرام، الصورة، رابط PDF والتخرّج.
- `projects`: المشاريع وأوصافها وتصنيفاتها وروابطها.
- `skillGroups`: مجموعات المهارات.
- `softSkills`: المهارات الشخصية.
- `courses`: الدورات.
- `interests`: الاهتمامات.
- `copy.ar` و`copy.en`: نصوص واجهة الموقع بالعربية والإنجليزية.

لكل معلومة مترجمة نسختان، مثل:

```js
firstName: { ar: "عبدالله", en: "Abdullah" }
```

احفظ الملف بترميز UTF-8. حافظ على علامات الاقتباس والفواصل والأقواس. حدّث النص العربي والإنجليزي معًا.

## أزرار التواصل

زر «تواصل معنا» يظهر خيارات واتساب وتيليجرام. القيم الحالية:

```js
email: "dev.alnumary@gmail.com",
whatsapp: "967770471325",
telegram: "at2ss"
```

رقم واتساب مكتوب بمفتاح الدولة دون علامة + أو مسافات. اسم تيليجرام مكتوب دون @. تُنشأ الروابط تلقائيًا من هذه المعلومات. الموقع لا يرسل الرسائل بنفسه؛ الزر يفتح المحادثة في الخدمة المختارة، ثم يكتب الزائر رسالته.

## إضافة روابط المشاريع

داخل كل مشروع في `projects` ستجد:

```js
url: ""
```

أضف رابطًا كاملًا يبدأ بـ `https://`، وسيظهر زر «زيارة المشروع» تلقائيًا. تُركت هذه القيم فارغة لأن روابط المشاريع الأصلية لم تكن ضمن المعلومات المقدمة.

الأغلفة الحالية تصاميم كتابية توضيحية؛ ليست لقطات من واجهات المشاريع الفعلية، وهذا موضّح في الصفحة. لإضافة لقطات حقيقية لاحقًا، ضع الصور في `assets/images` ثم عدّل قالب المشروع `project-template` في `index.html` وتنسيقه في `styles.css`.

## تغيير الصورة والسيرة القابلة للتنزيل

- الصورة الشخصية: `assets/images/abdullah.jpg`.
- السيرة بصيغة PDF: `assets/documents/Abdullah-Alnumary-CV.pdf`.
- الصورة الأصلية للسيرة: `assets/images/original-cv.jpg`.

استبدل الملف مع الاحتفاظ بالاسم، أو حدّث المسار داخل `person` في `profile.js`. ملف PDF المرفق تحويل كامل للصورة الأصلية للسيرة المقدّمة. تعديل نصوص الموقع لا يغيّر محتوى PDF تلقائيًا؛ استبدله بنسخة محدثة عند تغيير المعلومات.

## تعديل الألوان والخطوط والحركة

الألوان الرئيسية موجودة في بداية `styles.css` داخل `:root`:

```css
--paper: #f5f3ed;
--ink: #20272e;
--blue: #263fce;
--blue-deep: #18265b;
```

الخط العربي Alexandria والإنجليزي Manrope، محفوظان محليًا مع تراخيصهما في `assets/fonts`.

توجد حركة دخول قصيرة، ومجسّم هندسي متحرك، وانتقالات للمحتوى التفاعلي. يمكن إيقاف المجسم من زر الإيقاف داخل المساحة الزرقاء. كما يحترم الموقع إعداد «تقليل الحركة» في جهاز الزائر.

اللغة الافتراضية العربية. يتذكر الموقع اختيار اللغة والحركة في المتصفح عندما يسمح المتصفح بالتخزين المحلي.

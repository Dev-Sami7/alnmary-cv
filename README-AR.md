# موقع عبدالله النماري — النسخة الداكنة المتحركة

موقع سيرة ذاتية بالعربية والإنجليزية، بألوان داكنة وحركة متقدمة باستخدام GSAP. المشروع HTML وCSS وJavaScript؛ جميع الصور والخطوط ومكتبات الحركة محلية، ولا يحتاج إلى npm أو خطوة بناء.

## فتح الموقع

فك الضغط بالكامل، ثم افتح `index.html` من داخل مجلد `abdullah-cv` في متصفح حديث. لا تنقل ملف HTML وحده؛ احتفظ بجميع المجلدات والملفات المرفقة.

## الموقع المنشور

- الموقع: https://dev-sami7.github.io/alnmary-cv/
- المستودع: https://github.com/Dev-Sami7/alnmary-cv
- النشر من فرع `main` ومجلد الجذر `/` باستخدام GitHub Pages.
- ملف `.nojekyll` يتيح نشر الملفات الثابتة مباشرة.

عند تحديث المستودع، تنشر GitHub Pages التحديث تلقائيًا بعد نجاح عملية النشر.

## الرفع إلى Netlify

1. سجّل الدخول إلى حسابك وافتح https://app.netlify.com/drop .
2. اسحب المجلد الذي يحتوي `index.html` مباشرة إلى منطقة الرفع.
3. لا يحتاج الموقع إلى Build command. إعدادات أساسية موجودة في `netlify.toml`.
4. بعد النشر، جرّب الرابط في نافذة خاصة قبل مشاركته.

## تعديل المعلومات

معظم البيانات والنصوص في `profile.js`:

- `person`: الاسم، الصورة، البريد، رقم واتساب، اسم تيليجرام، رابط السيرة PDF والتخرّج.
- `projects`: عناوين المشاريع وأوصافها وصورها وروابطها.
- `skillGroups` و`softSkills`: المهارات التقنية والشخصية.
- `courses` و`interests`: الدورات والاهتمامات.
- `copy.ar` و`copy.en`: نصوص الواجهة باللغتين.

مثال:

```js
firstName: { ar: "عبدالله", en: "Abdullah" }
```

عدّل النسختين واحفظ الملف بترميز UTF-8، مع الحفاظ على الأقواس والفواصل وعلامات الاقتباس.

## الصور والمشاريع

تصاميم الواجهات الجديدة موجودة في `assets/images`:

- `showroom-concept.jpg`: تصوّر واجهة معرض السيارات.
- `restaurant-concept.jpg`: تصوّر واجهة إدارة المطعم.
- `cpp-concept.jpg`: تصوّر مساحة حل مسائل C++.

هذه تصوّرات صُممت لهذا العرض، وليست لقطات من التطبيقات الأصلية، وهذا مذكور في الصفحة. يمكن تكبيرها من زر «تكبير الواجهة». لإضافة لقطات فعلية لاحقًا، ضع الصورة في المجلد وعدّل `image` داخل المشروع المناسب في `profile.js`.

إذا أضفت رابطًا كاملًا يبدأ بـ `https://` إلى `url` داخل أحد المشاريع، يظهر رابط زيارته تلقائيًا. القيم فارغة حاليًا لعدم تزويدنا بروابط أصلية للمشاريع.

## الألوان والحركة

الألوان في بداية `styles.css` داخل `:root`:

```css
--bg: #0e0d14;
--surface: #17151f;
--ink: #f1edf7;
--accent: #c6afea;
```

الحركة في `script.js` داخل `setupMotion`. النسخة المكتبية تعرض المشاريع كإطارات متراكبة عند التمرير. على الهاتف تظهر المشاريع في ترتيب طبيعي مع انتقالات مناسبة للمساحة. يوجد زر لتقليل الحركة في أعلى الصفحة، ويحترم الموقع إعداد «تقليل الحركة» في نظام الجهاز.

الخط العربي Alexandria والإنجليزي Geist. مكتبات الحركة المحلية موجودة في `assets/vendor`. احتفظ بها عند نقل المشروع.

الملفات الرئيسية: `index.html`، `styles.css`، `profile.js`، `script.js`، ومجلد `assets`. لا توجد قاعدة بيانات أو لوحة إدارة أو خدمات خارجية مطلوبة لتشغيل الموقع. مصادر الصور والخطوط والمكتبات موثقة في `assets/ASSET-SOURCES.md`.
